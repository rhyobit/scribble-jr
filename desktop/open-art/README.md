# Open art

All of Scribble Jr's library and brand art. Everything drawn for this project is
CC0 (below); the library characters in `characters/` are Twemoji (CC BY 4.0, see
`../../CREDITS.md`).

| File | Character |
|---|---|
| `svglibrary/Tabby.svg` | Tabby: round grey tabby with a teal collar |
| `svglibrary/Plum.svg` | Plum: tall purple cat with freckles and a curly tail |
| `svglibrary/Nova.svg` | Nova: navy cat with a star chest patch and red boots |

- `svglibrary/` is generated by `tools/make-cats.mjs` (edit the shapes there, then
  re-run it). Shapes carry their own fill/stroke and use only cubic curves,
  because ScratchJr's paint editor ignores group styles and quadratic curves.
- `pnglibrary/` holds the 140px-high library thumbnails.
- `media-additions.json` lists the characters; `../assemble.mjs` merges them into
  the library and adds their names to every locale file.

## Brand art (Scribble Jr, CC0)

The brand art below is also covered by the CC0 dedication above. It is generated
by `tools/make-brand.mjs` (edit the shapes there, then re-run it), which writes the
app files and a copy of each into `brand/`. The mascots reuse Tabby, Plum and Nova
from `svglibrary/`; Sparky the robot is new. Same shape rules as the characters,
plus: absolute `M/L/C/Z` path data only, one wrapping `<g>`, no `<text>` (letters
are drawn as paths so they render as CSS backgrounds), no transforms, gradients or
filters. Some file names still say "ScratchJr" only so the existing CSS keeps working.

## Library characters (Twemoji, CC BY 4.0)

`characters/` holds 147 characters converted from [Twemoji](https://github.com/jdecked/twemoji)
v17.0.3 (graphics licence CC BY 4.0, attribution in `../../CREDITS.md` and the app's About page).
They are regenerated with:

```bash
node tools/make-twemoji-characters.mjs <path to twemoji>/assets/svg
```

`make-twemoji-characters.mjs` holds the chosen emoji and their names and library sections;
`svg-to-sjr.mjs` converts any SVG into the form ScratchJr's paint editor can edit (paths with
absolute M/L/C/Z only, transforms and group styles applied, explicit fill/stroke on every shape).
`pnglibrary/` thumbnails (140 px high for characters) are rendered from the SVGs in a browser.

## Backgrounds

Twenty original 480 x 360 scenes in `backgrounds/`, released under the same CC0
dedication as everything else in this folder:

Park, Farm, City, Beach, Underwater, Space, Moon, Forest, Snow, Desert, Jungle,
Mountains, Castle, Classroom, Bedroom, Kitchen, Playground, Night Sky, Stage,
Garden.

- Flat colours with a dark `#2b2b33` outline on foreground objects only, soft
  skies, and a clear ground or floor around y = 240-270 so characters have
  somewhere to stand. The middle of each picture is kept fairly open.
- `backgrounds/` is generated by `tools/make-backgrounds.mjs` (edit a scene there,
  then re-run `node desktop/open-art/tools/make-backgrounds.mjs`). It also writes
  `backgrounds/backgrounds.json` (`md5`, `width`, `height`, `ext`, `name` per scene).
- To stay readable by ScratchJr's paint editor, the files use only `<path>`,
  `<circle>`, `<ellipse>`, `<rect>` and `<polygon>` inside one `<g id="Name.svg">`;
  every shape has its own `fill` and `stroke`; there are no transforms, gradients,
  opacity or CSS; and path data uses only absolute `M`, `L`, `C`, `Z` (curves and
  arcs are cubic Beziers). Randomised details (stars, snow) use a fixed seed, so
  re-running the generator gives identical files.
- `tools/check-svg.mjs` checks those rules and exits non-zero on any violation:

  ```
  node desktop/open-art/tools/check-svg.mjs --size 480x360 desktop/open-art/backgrounds
  ```

  It takes any mix of files and folders, so it can be used on other art too.
  Options: `--size WxH` (require that canvas, warn about shapes far off it),
  `--max-bytes N` (default 61440) and `--max-elements N` (default 400).
